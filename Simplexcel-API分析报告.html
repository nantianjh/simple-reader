一、软件架构

技术栈：vercel/pkg 5.8.1 打包的 Node.js 18（node18-win-x64）单文件 HTTP 服务。内嵌 package.json 显示：main: server.js，前端资源以 pkg.assets: ["public/**/*"] 明文嵌入，server.js 主逻辑编译为 V8 字节码（快照路径 C:\snapshot\simple\server.js）。

浏览器 Excel 风格 UI（明文前端）⇄ HTTP 本地服务 localhost:3000 起（占用自动顺延）⇄ HTTPS 代理 simple.imsummer.cn API v2

所有远端请求由本地服务器中转，浏览器 UI 不直接连远端。Token 存于 exe 同目录 config.json，可被环境变量 SIMPLE_TOKEN 覆盖。

四、媒体与静态资源

  • 图片/视频/音频一律走本地 /media?url= 代理转发到 static-simple.imsummer.cn（MEDIA_HOST 常量），服务器端透传 Range / Content-Range，附加 Cache-Control: public, max-age=86400。
  • 缩略图用七牛云参数 ?imageView2/2/w/300 在源 URL 上追加。
  • Token 无效时 UI 提示「登录已失效：请重新登录后在 config.json 中更新 token」（HTTP 401 分支）。

五、缓存机制（server.js 内部）

  • POST_CACHE / POST_CACHE_TTL — 帖子列表缓存
  • FAV_CACHE / FAV_CACHE_TTL — 收藏缓存
  • COMMENT_CACHE / COMMENT_CACHE_TTL — 评论缓存
  • ME_CACHE — 用户信息缓存；clearApiCaches 在点赞/收藏/评论写操作后清缓存
